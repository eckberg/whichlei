# Specs

One spec per slice in PLAN.md, written before the slice starts and approved by the owner.
Name it `NN-slug.md`. Keep it under a page; if it runs longer, split the slice.

```markdown
# NN · Slice name

Status: draft | approved | done

## Goal
What someone can do afterwards that they could not before. One paragraph.

## Scope
## Not in scope
The things a reader would assume are included.

## Approach
How, briefly. Alternatives considered, and why not.

## Unknowns
What we do not know yet, and how we find out: measure, spike, or ask.

## Done when
Checkable conditions, each with its evidence: a number, a test, a screenshot.
```

If the spec changes during the slice, update it and say why.
