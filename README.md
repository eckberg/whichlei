# whichlei

Which LEI does this entity have? Type a name, an LEI, an ISIN, a BIC or a national register
number and get the Legal Entity Identifier while you type. Copy it and leave.

Free, with no account and no cookies. Data from GLEIF, published under CC0.

In development. What it is and why is in [DESIGN.md](DESIGN.md), the build plan in
[PLAN.md](PLAN.md), and the ranking research in [research/ranking](research/ranking/).
